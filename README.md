# Poster Sorter

An Android app that finds event posters in your WhatsApp images and moves them to
`Pictures/Event Posters`, leaving photos of family and friends where they are.

- Reads English, Urdu and Arabic text on the phone. Nothing is uploaded.
- Posters, "Not sure" and "Kept" tabs. Tap to select, hold to view.
- Move to Event Posters (with undo) or delete.

## Install

1. On your phone, open the **Releases** page of this repository and download `PosterSorter.apk`.
2. Open it. Android asks to allow installs from your browser; allow it.
3. Open Poster Sorter and give it "Allow access to manage all files".

Every push to `main` builds a new version automatically (see **Actions**).
New versions install over the old one.

Needs Android 11 or later.
